## Reproduce

Check out this checkpoint's source, install the locked dependencies, then from repo root:

```sh
node .agents/reviews/astra-sleeve-monotone/geometry-review.mjs
node .agents/reviews/astra-sleeve-monotone/contact-review.mjs
```

Both scripts assert the reviewed helper hash, read the old helper from immutable579078c,
and write results under gauntlet/tmp/monotone-sleeve-replay. Input states are an exact
subset of the archived real capture identified in capture-inputs.json. They do not require
a browser, remote image fetch or the original scratch environment. Retained results came
from the original equivalent scratch checkers. Contact output is condensed, retaining
counts/distances and face-list hashes; fullResultSha256 identifies the complete replay JSON.
The full report is regenerated by the contact checker; packaged paths/base selection were pinned
for portability, and syntax was checked. Geometry replay also passed after packaging.

The shared triangle utility omits only exactly zero-area inherited faces; it does not
hide small valid faces. These are bounded static configurations, not swept collision.
