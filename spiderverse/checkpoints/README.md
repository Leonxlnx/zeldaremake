# Video checkpoints

Every cut of *Into the Ant-Verse* that gets watched is preserved here, one folder per
checkpoint, alongside the git tag that reproduces it (`antverse-cpNN-*`).

| Folder | Tag | What it is |
| --- | --- | --- |

Each folder holds the MP4 (tracked with Git LFS), its `.verify.json` from
`tools/assemble.mjs`, and `NOTES.md` describing what changed and what the review found.
Full-resolution deliveries are also published as run artifacts under `/opt/cursor/artifacts/`.
