# Generated character: redistribution review

Reviewed 2026-09-14 following the owner's explicit open-source question.
This records unresolved rights questions; it is not a legal clearance or an asset license.

The production body/base maps derive from the Rodin Gen-2.5 two-view job
`03f2d679-4d9f-412a-a855-25630f526349`, submitted through the bundled Blender MCP public
trial. The request and image hashes are in `experiments/2026-09-13/rodin-multiview-gen25-request.json`.
This includes the descendants `9189538d` (Fable ad01908/take0085), `6f28903d` (PR10),
and the local `2106700b` arm-motion study. These assets have already been pushed in the
repository except for the latest local arm study; this document does not undo publication.

[Hyper3D's current terms](https://hyper3d.ai/legal/terms), section5(b), broadly permit
Rodin output use, subject to the agreement and third-party rights. Section6.3 includes
content-transfer restrictions and obligations to notify recipients. Section2 also allows
service-specific conditions. The applicability of those terms to unrestricted downstream
redistribution and relicensing of this bundled-trial output has not been resolved.
No separate trial-specific grant was found in the checked public documentation.
The restrictive ChatAvatar provisions in5(a) should not be misreported as Rodin's license.

The [Blender MCP README](https://github.com/ahujasid/blender-mcp) documents the trial's
generation allowance. Its MIT software license does not establish a license for a
third-party service's generated assets. No model-specific MIT/CC0 permission is recorded.

Open-source software licensing includes downstream redistribution and modification rights;
public GitHub availability alone is insufficient. See the [Open Source Definition](https://opensource.org/osd).
No root project LICENSE file was found in the reviewed checkout. Do not add a blanket
license that silently includes these assets. Code and asset licensing can be documented separately.

The project deliberately depicts Link/Zelda. Original mesh generation and Blender editing
do not establish permission for the underlying character/design. Under
[German UrhG section23](https://www.gesetze-im-internet.de/urhg/__23.html), publishing an
adaptation generally requires consent unless the work maintains sufficient distance.
No Nintendo permission is recorded; open source/noncommercial status is not itself clearance.

Next step: obtain an explicit provider clarification covering raw GLB/texture/Blender source
redistribution, modification and downstream commercial reuse under a chosen open asset
license, or use assets with already documented suitable rights. Underlying character rights
remain a separate question. No provider has been contacted and no purchase authorized.
Local rig/animation studies can continue without representing their assets as release-cleared.
