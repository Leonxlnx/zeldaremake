# Generated Link modelling references

These are generated reference images, not Blender output, game screenshots or an art acceptance claim. Created with the built-in image generation tool at the owner's request. Exact prompts and limitations are in `prompts.json`; file hashes and dimensions are in `manifest.json`.

- `01-head-hair-materials.png`: face views, flowing hair, skin and cloth. The face is more mature than the intended hero: use it for hair/material construction, not the final facial proportions.
- `02-boots.png`: instep, ankle cuff, heel, sole and leather construction from multiple views.
- `03-clothing-equipment.png`: tunic drape, cap, backpack, shield and material details.
- `04-full-body.png`: a single front/A-pose reference generated from the first figure on the original Kokiri hero sheet. This successful request supersedes the earlier failed full-body attempts. It preserves the compact proportions and provides one clear subject for 3D generation; it is not a script crop or a rendered Blender model.

The original `reference/concepts/03_kokiri_hero_link_sheet.jpg` and the ten owner concept previews remain the target for the hero's proportions and art direction. Generated views can disagree in small details; choose one coherent construction in Blender. These images must never replace geometry or be used as in-game scenery.

The current Blender character is below these targets. Next visible corrections: flowing layered hair instead of thick tubes; soft continuous youthful facial anatomy; weighted cloth folds and a cap that sits behind the fringe; leather boots with a continuous instep and flexible ankle.
